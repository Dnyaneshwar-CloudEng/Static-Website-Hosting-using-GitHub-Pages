# Static Website Hosting using GitHub Pages

## Project Overview
This project demonstrates how to create and deploy a static website using HTML, CSS, Git, GitHub, and GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Project Implementation
1. Created a static website using HTML and CSS.
2. Managed project files using Git.
3. Pushed the source code to a GitHub repository.
4. Configured GitHub Pages to deploy the website from the main branch.
5. Verified the website using its public URL.
